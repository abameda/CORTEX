=== VISUAL IDENTITY ===

Logo: The Neural Mark — abstract network of interconnected nodes forming a brain-like neural network. Varying opacity of connections suggests intelligence at work.

Logo formats:

- Primary: Icon + wordmark, horizontal lockup (use whenever space permits)
- Icon only: Neural Mark standalone (app icons, favicons, social avatars, watermarks)
- Wordmark only: CORTEX text without icon (only when icon is already established in context)

Logo color treatments:

- Chartreuse on black (default and preferred)
- Black on white (inverse, for light backgrounds and print)
- Black on chartreuse (high-impact moments only, use sparingly)

=== COLOR SYSTEM ===

Primary palette: Black + Chartreuse

Background tones:

- Base: #000000
- Surface: #0A0A0A
- Elevated: #141414
- Border: #1A1A1A

Accent system:

- Accent deep: #7A9900
- Accent primary: #C8FF00 (Chartreuse)
- Accent light: #E8FF80

Text hierarchy:

- Primary: #FFFFFF
- Secondary: #888888
- Muted: #555555
- Subtle: #333333

Usage rules:

- Chartreuse is an accent, NOT a background. Use for CTAs, highlights, active states, key data points, and the logo.
- Black is the environment. The gradient from #000000 to #141414 creates card hierarchy.
- White text on black always. Primary content is always white.

=== TYPOGRAPHY ===

Primary typeface: Inter — clean, modern, screen-optimized. Used for all body text, UI, navigation, and communications.

- Regular (400): Body text, descriptions
- Medium (500): Headings, navigation, button labels
- Bold (700): Hero headlines, key statistics

Display typeface: Space Grotesk (or equivalent geometric sans) — used for hero sections and large display headings at 28px+ only. Never in body text.
